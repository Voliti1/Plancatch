# 마감 준비 상태

`GET /api/deadlines/{id}/readiness`는 현재 로그인한 사용자의 마감일·연결된 할 일·로컬 배치만 조회합니다.
다른 계정/없는 마감일은 404, 로그인 없으면 401이며 응답은 `Cache-Control: no-store`입니다.
DB·Google 일정·분석 기록·토큰을 변경하거나 외부 서비스를 호출하지 않습니다.

목표 시각은 안전 마감일이 있으면 안전 마감, 없으면 공식 마감입니다.
우선순위는 완료 → 공식 마감 도달 → 안전 마감 도달 → 명백한 시간 부족 → 정보 부족 → 배치/임박 확인 → 계획 있음입니다.

| 값 | 화면 | 기준 |
|---|---|---|
| completed | 할 일 완료 | 연결된 할 일이 있으며 전부 완료 표시, 조회 누락 없음 |
| overdue | 마감 지남 | 공식 마감 시각 도달 |
| attention | 확인 필요 | 안전 마감 도달, 배치 부족/겹침, 24시간 이내, 날짜 미확인 |
| shortage | 시간 부족 | 알려진 미완료 예상 시간만으로도 목표까지 남은 전체 시간을 초과 |
| unknown | 정보 부족 | 연결 작업 없음, 소요시간 없음/반복 작업, 조회 상한 |
| planned | 계획 있음 | 위 조건 없이 알려진 작업별 예상 시간만큼 목표 전 배치가 있음 |

안전 마감 도달은 공식 마감 초과와 구분합니다. 현재 시각은 서버 UTC를 사용하고 화면은 한국 시간입니다.
반복 작업/반복 예외는 남은 횟수·진행률을 임의 추정하지 않아 정보 부족으로 처리합니다.
완료되지 않은 작업의 전체 예상 시간을 사용하며 지난 배치를 실제 완료로 간주하지 않습니다.
고정 할 일에 예상 시간이 없으면 원래 시작·종료 구간의 길이를 올림한 분을 사용합니다.

배치는 승인/전송 상태만 인정합니다. 추천/취소는 인정하지 않고, 고정 원본 시간은 어떤 배치 기록도
없는 경우에만 인정해 기존 캘린더와 동일하게 취소된 원본을 다시 계산하지 않습니다.
현재~목표 구간 및 유동 할 일의 가능 기간으로 자릅니다. 고정 할 일의 실제 배치 이동은 원래 고정 시간으로
자르지 않습니다. 같은 작업의 중복·겹친 구간은 합치고 초 단위를 합산한 뒤 분을 내림하며 예상 시간보다 많이
확보했다고 계산하지 않습니다. 알려진 작업 간 배치가 겹치면 확인 필요입니다.

최대 할 일 200개·배치 2,000개(+누락 여부 확인용 1개), 고정 원본 대체 여부 조회도 선택한 할 일 ID 안에서만
수행합니다. 잘린 결과나 소요시간 미정이 있으면 총 예상/추가 필요 시간은 null이며 알려진 부분 시간만 표시합니다.
이미 증명된 공식 마감 초과/시간 부족은 정보가 일부여도 표시하되 누락 이유를 함께 반환합니다.

다른 마감일의 작업, Google 개인 일정, 작업 가능 요일/일과 시간과 실제 수행률까지 계산한 성공 확률이 아닙니다.
‘계획 있음’은 기록된 배치의 확보 여부입니다. 실제 가능한 시간대와 외부 겹침은 기존 자동 배치에서 확인합니다.
화면은 마감일 상세에서 조회하며 다시 확인 버튼·마감일 저장·연결 할 일 완료 상태 변경 후 새로 조회합니다.
자동 폴링·전체 목록별 추가 조회는 하지 않습니다. DB 구조/환경/권한 변경은 없습니다.
