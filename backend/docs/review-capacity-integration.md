# 원문 검토와 마감 위험도 통합

PR #135의 분석 당시 원문 비교, #136의 PDF 근거 페이지·이미지 원문 교정을
#137~#140의 중단 복구·가능 시간·작업 계획·마감 위험도 위에 통합한다.
별도 DB 구조 변경이나 기존 자료의 일괄 재분석은 없다.

- 이미지 글 교정도 원본과 새 분석에 같은 실행 번호·유효 시간을 부여하며 기존
  heartbeat/늦은 결과 차단을 유지한다. 교정 중단 시 이전 추출 원문은 그대로 사용할 수 있다.
  실패한 새 분석은 재시도할 수 있으며 자동으로 AI에 재전송하지 않는다.
- 이미지 교정은 사용자가 선택·동의한 글만 기존 AI 경로로 전송한다. 이미지 원본은
  교정 요청에 다시 전송하지 않는다. 성공한 새 결과를 별도로 검토·승인해야 등록된다.
- PDF 근거 페이지는 실제 추출한 페이지 번호만 표시한다. 전사 결과의 페이지를
  알 수 없으면 추측하지 않는다. 분석 당시 저장 원문은 현재 자료와 별도로 표시한다.
- 마감 위험도는 저장 가능 시간·기존 일정·미완료 선행 작업을 읽어서 계산한다.
  실제 예약이나 성공 확률을 의미하지 않는다. 상세는 `deadline-capacity-risk.md`를 따른다.

통합 검증: 백엔드 전체 1,127 통과·선택 PostgreSQL 15 건너뜀, Ruff,
프론트 lint/typecheck/생산 build 및 PC·모바일 원문/이미지/PDF/위험도 화면 56개 통과.
분석 중 유효한 실행 번호, 원문 보존, 중단 복구의 두 진입 경로를 추가 검사했다.
AI 응답은 합성하며 실제 개인 일정/파일의 외부 전송은 하지 않는다.

복구는 직전 운영 PR #139 코드와 화면을 함께 사용한다. 기존 DB 구조와 사용자 데이터는
유지한다. PR #139보다 더 오래된 코드의 작업 순서 보호는 해당 배포 기록을 따른다.
