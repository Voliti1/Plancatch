# 등록 마감일이 있는 원본 자료 삭제 보호

POST/PATCH로 저장했거나 분석 결과를 승인해 생성한 Deadline이 하나라도 source_id로 연결돼 있으면
DELETE /api/sources/{id}는409/source_has_deadlines를 반환합니다. is_confirmed 여부와 무관합니다.
검토 후보만 있고 아직 Deadline으로 등록하지 않았다면 이 보호 조건에 해당하지 않습니다.
연결된 마감일을 모두 삭제하거나 source_id 연결을 해제한 뒤에는 기존 자료 삭제가 가능합니다.
삭제 거부 시 원본/마감일/분석/연결된 작업은 그대로 보존됩니다. 소유권 확인이 먼저입니다.

자료 행을 잠근 상태에서 연결 여부를 확인하고 삭제합니다. 수동 마감일 등록/자료 연결 변경도
같은 자료 행 잠금을 사용합니다. 분석 API는 자료→분석 순으로 잠가 승인·삭제의 잠금 순서를 맞춥니다.
기존 DB 외래키/구조 변경은 없습니다. 보호는 애플리케이션의 공개 API에 적용됩니다.

목록과 상세에서 한국어 삭제 거부 이유를 표시하며, 목록에서는 거부된 항목 선택을 유지합니다.
연결 없는 자료만 기존처럼 삭제되고 Google 일정은 자동 삭제하지 않습니다.
이전 코드로 롤백하면 이 보호 정책도 사라지므로 복구 시 정책 차이를 확인해야 합니다.
