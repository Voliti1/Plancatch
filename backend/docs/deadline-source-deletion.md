# 마감일 삭제와 원본 자료 정리

- `DELETE /api/deadlines/{id}`는 소유한 마감일을 삭제하고, 그 자료를 가리키는 다른 마감일이
  하나도 남지 않으면 소유한 원본 자료와 분석 기록도 같은 DB 트랜잭션에서 삭제한다.
- 여러 후보를 승인해 같은 자료에 마감일이 여러 개 연결된 경우 마지막 삭제 때만 원본을 정리한다.
  연결 없는 수동 마감일이나 다른 사람/다른 자료는 정리 대상이 아니다.
- 자료 추출이나 AI 분석이 진행 중인 마지막 연결 자료는 둘 다 유지하고409 `deadline_source_busy`를 반환한다.
  완료 후 사용자가 다시 삭제할 수 있다. 자료 연결이 동시에 바뀌면409 `deadline_source_changed`로 새로고침을 요청한다.
- 자료 부모 행 → 마감일 행 순서로 잠근다. 등록/승인/직접 원본 삭제와 같은 순서를 따르며
  자료 변경도 부모 ID 정렬 후 잠가 교착을 피한다. 파일은 DB 커밋 후에만 지운다.
- 기존 할 일은 보존하고 마감일 연결만 해제한다. Google Calendar 일정은 원격 삭제하지 않는다.
  목록·상세 화면에서 삭제 결과를 안내하며 기존 두 번 확인 동작을 유지한다.
- 원본 자료를 직접 지울 때 마감일이 남아 있으면409로 거부하는 기존 동작은 유지한다.
  DB 구조 변경 없음. 삭제는 사용자가 선택한 항목에만 적용되며 배포 시 기존 자료를 일괄 정리하지 않는다.
