# 마감 시간 처리 — 2026-10-27 사용자 요청 반영

- 날짜가 명확하고 시간만 없으면 한국 시간 **23:59**를 검토 후보에 미리 입력한다.
  화면에는 “마감 시간이 없어 오후 11시 59분으로 설정했습니다. 필요하면 변경해 주세요.”라고 안내한다.
  실제 명시 시각을 읽은 것으로 표현하지 않는다. URL·사진·텍스트에 동일하게 적용한다.
- `2026년 10월 27일(화) 오후 5시(한국시간)`은 **2026-10-27T17:00:00+09:00**이다.
  오전/오후 12시, 같은 연도를 공유하는 접수기간, 물결표 변형, 명시된 24:00을 처리한다.
  실제 시각·초·소수초·명시 오프셋은 보존한다.
- 연도 없는 날짜, 잘못된 날짜/요일/시각, 상충하는 날짜, 채용 시 마감은 임의 확정하지 않는다.
  별도로 명시한 해외 시간대는 한국 시간 기본값으로 덮지 않는다.
- URL은 기존 본 공고 범위/공고 식별·사이트별 비교를 통과해야 한다. 추천 공고의 날짜를 사용하지 않는다.
  날짜만 있는 후보와 사진 후보는 선택하지 않은 상태로 표시하며 사용자가 선택·승인한다.
  새 기본 시간 안내는 자동 등록을 우회하는 허가가 아니다. Google 전송을 자동 실행하지 않는다.
- API 날짜 선택지와 후보에는 `time_defaulted`가 추가된다. 이전 분석은 원문을 바꾸지 않고
  안전하게 확인 가능한 날짜에 한해서, 미검토(revision1/ready) 후보에 읽기 전용 `suggested_due_at`을 제공한다.
  화면은 이를 채우되 먼저 저장해야 승인할 수 있다. 사용자 수정/비움 후 다시 채우지 않는다.
  GET은 DB·원문·기존 마감일을 변경하지 않고 AI를 재호출하지 않는다. DB 구조 변경 없음.
- AI 안내의 개발자 표현은 일반 한국어로 표시한다. 합성 이미지·응답으로 검증하며 사용자 캡처는 재전송하지 않았다.

이 정책은 이전 문서의 “시간 누락은 항상 비워 두고 사용자가 입력” 규칙을 대체한다.
개별 사이트의 원문 접수기간은 그대로 보존하고, 적용 시간과 원문 시간을 구분한다.
