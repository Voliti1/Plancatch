# 링커리어 접수기간 구조 차이 수정 (2026-11-12)

`/activity/361835`의 공개 HTML은 `접수기간` dt에 대응하는 dd 안에 날짜 범위를
직접 기록한다. 기존 파서는 시작일/마감일 라벨과 날짜가 별도 span 4개로 나뉜
구조만 허용해 이 필드를 놓쳤다. 공통 보완 경로도 텍스트 3줄까지만 확인해
`접수기간 / 시작 날짜 / ~ / 종료 날짜`에서 종료일을 읽지 못했다.

- 링커리어는 같은 공고 본문의 접수기간 dd 전체에서 한 개의 명시적 날짜 범위도
  읽는다. 기존 4개 span 형식은 유지한다. 댓글·인라인 태그로 나뉜 텍스트도 지원한다.
- 공통 경로는 최대 8줄/500자 안에서 연속된 날짜·구분자·시각만 이어 읽고
  다른 항목 라벨이나 일반 문장을 만나면 멈춘다. 날짜 범위의 종료일에만 후보를
  만들며 범위에 명시된 연도만 이어받는다. 시작일만 있는 기간은 마감일로 만들지 않는다.
- 시각이 다음 줄에 명시돼 있으면 유지하며, 잘못된 시각은 23:59로 덮지 않는다.
  시간이 정말 없는 날짜만 기존 정책에 따라 한국 시간 23:59를 제안한다.
- 공고 ID/제목/canonical·메타데이터와 표시 날짜 대조, 충돌·복수 후보의 사용자
  검토, 추천 공고 제외, 숨김 처리, 공개 접근·robots·최대 크기 제한은 유지한다.
- 같은 공고의 명시적 메타데이터 시각이 있으면 기존 우선순위를 유지하며 그 출처를
  안내한다. URL에서 이미지를 AI로 읽거나 게시되지 않은 시간을 추정하지 않는다.

실제 HTML 저장본에서 종료일/시각 후보와 회사명 출력을 확인했다. 최종 백엔드
전체 1,023개 통과·선택 PostgreSQL 검사 13개 제외·Ruff 통과. 구·신 HTML에서
검토·수정·승인·재시도와 시각 보존, 다른 필드/숨김/중복/메타데이터 충돌을 검사했다.
기존 저장된 원문/분석을 일괄 수정하지 않는다. 수정 전 추출 기록은 원문을 다시
추출한 뒤 새 검토 결과로 확인해야 한다.
