# 자소설닷컴 접수기간 추출·검토

공개 `/recruit/{공고번호}` 페이지의 접수기간과 같은 HTML의 시간대 명시 데이터를
대조하여 기존 HTML 검토·수정·승인 흐름으로 연결합니다. 외부 AI를 호출하지 않습니다.

## 시간대와 공고 식별

2026-10-27 실제 공고 `106909`에서 기존 수집 절차로 확인한 값은 다음과 같습니다.

| 근거 | 시작 | 종료 |
| --- | --- | --- |
| 서버 HTML의 표시 문자열(시간대 없음) | 2026년 10월 26일 09:00 | 2026년 11월 7일 14:50 |
| 같은 HTML의 원본 일시 데이터 | 2026-10-26T18:00:00.000+09:00 | 2026-11-07T23:50:00.000+09:00 |

브라우저에서 확인한 한국 시간은 18:00 → 23:50입니다. 서버 표시 문자열을 곧바로
한국 시간으로 간주하면 9시간 이른 마감일이 됩니다. 이 어댑터는 다음을 모두 검증합니다.

- 공식 `jasoseol.com` / `www.jasoseol.com`의 숫자 공고 경로와 같은 출처·공고 ID의
  canonical URL을 확인합니다.
- `__NEXT_DATA__`의 `query.slug`, `pageProps.employmentCompanyId`,
  `pageProps.initialEmploymentCompany.id`가 모두 해당 공고 번호여야 합니다.
  페이지 유형과 유일한 h1 제목도 원본 공고 제목과 일치해야 합니다.
- `start_time`과 `end_time`은 초·시간대가 명시된 ISO 일시여야 하며 종료가 시작보다
  뒤여야 합니다. 추천 광고·하위 직무의 날짜, 상대 남은 일수는 사용하지 않습니다.
- 표시 문자열의 시작·종료가 함께 한국 시간 또는 함께 UTC로 변환한 원본 일시와
  분 단위까지 일치해야 합니다. 한쪽만 UTC인 경우나 다른 날짜·시간은 자동 확정하지 않습니다.
  표시 정밀도가 분 단위일 때 원본 데이터의 초·소수초는 보존합니다.
- 시간대 명시 데이터가 없으면 무조건 9시간을 더하거나 현재 시간으로 역산하지 않습니다.
  여러 접수기간·제목·데이터 블록, JSON 중복 키, 잘못된 ID·시간대·표시 충돌은 직접
  확인하도록 마감 일시를 비웁니다.

## 제한과 응답

기존 공개 접근·robots·응답/텍스트 크기 제한을 유지합니다. 추가 요청, JavaScript 실행,
로그인 우회는 없습니다. JSON은 데이터 블록 하나·200,000자, 컨테이너 4,096개·32단계로
제한합니다. 화면 필드 300자·제목 1,000자, 수집 항목은 각각 최대 8개입니다.

기존 `source_period.site`에 `jasoseol`을 추가합니다. 원문 스냅샷에는 서버 표시 문자열과
시간대가 있는 원본 시작·종료 일시를 구분해 남깁니다. 응답의 `start_text`·`end_text`는
같은 HTML의 원본 일시이며, 화면에는 한국 시간 마감일을 함께 표시합니다.
새 API 경로·환경변수·DB·배포 설정은 필요하지 않습니다.

제공 공고의 마감 후보는 `2026-11-07T23:50:00+09:00`입니다. 사용자 승인 전에는
마감일을 생성하지 않습니다. 수정 revision·원문 변경 검사·중복 승인 방지는 기존 API를
사용합니다. 승인으로 작업·일정 블록·Google Calendar 이벤트를 만들지 않습니다.

백엔드와 프론트엔드 코드를 함께 반영해야 합니다. 이미 저장한 자료·분석은 자동으로
변경하지 않으며, 기존 자료에 적용하려면 다시 추출하고 새 검토를 시작해야 합니다.

## 검증

`tests/test_jasoseol_period.py`는 합성 HTML과 격리된 SQLite에서 UTC/한국 시간 표시,
혼합 시간대 거부, 정확한 공고 ID·제목·canonical·데이터 블록, 범위·중복·길이 제한,
제목 수정 후 시각 보존과 중복 승인을 확인합니다. DB 삽입 직전 오프셋도 검증합니다.
실제 URL은 기존 robots/DNS/IP 고정 수집 절차로 읽기 검증하며 RDS 데이터는 변경하지 않습니다.

`frontend/tests/jasoseol-period.spec.ts`는 PC·모바일에서 23:50 한국 시간 표시, 남은 기간,
제목 수정·승인·새로고침, 충돌과 승인 제한을 확인합니다. PC 브라우저는 LA 시간대를 써서
기기 설정에 따른 9시간 오차를 검사합니다. 가상 응답은 테스트에서만 사용합니다.
