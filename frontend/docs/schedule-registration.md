# 새 일정 등록

새 일정 등록하기는 `/sources/new`를 엽니다. 자료로 등록/수동 일정 등록을 선택하며,
단순 모드 전환은 초안을 유지하고 새 일정 버튼으로 다시 시작하면 입력과 파일을 초기화합니다.
저장 중에는 중복 요청과 모드 전환을 막고 실패 시 초안을 유지합니다.
이전 요청의 늦은 응답이 새로 시작한 화면을 이동시키거나 덮어쓰지 않도록 보호합니다.

## 일정 입력

‘일정 입력’ 카드의 ‘일정 제목 (선택)’은 새 마감일 후보 제목으로 이어집니다.
제목을 비우면 추출된 제목을 유지하며 검토 화면에서 다시 바꿀 수 있습니다.

URL·원본 텍스트·이미지 중 한 가지를 저장합니다. URL/텍스트는 POST /api/sources,
이미지는 POST /api/sources/images를 사용합니다. HTTP/HTTPS URL과 비어 있지 않은 텍스트만 받습니다.
이미지는 파일 선택/드롭/Ctrl+V로 첨부하며 저장 전에는 서버에 보내지 않습니다.
PNG/JPG/WebP/BMP/GIF/TIFF/AVIF 한 장(5MiB 이하)을 PNG로 변환해 보관합니다.
움직이는 이미지·여러 페이지·PDF/HEIC/SVG는 지원하지 않습니다.

저장 후 `/sources/[id]/review`로 이동하여 URL은 HTML을 직접 검토하고,
텍스트/이미지는 외부 AI 전송 동의 후 분석합니다. 분석 결과의 수정·선택·저장·승인 뒤 마감일이 생성됩니다.
URL에 있는 이미지는 자동으로 가져와 분석하지 않습니다. 날짜만 있으면23:59를 제안하고 직접 검토합니다.
이전 URL 전용 `/deadlines/auto` 진입도 유지하지만 신규 흐름과 사용자 확인 정책을 공유합니다.

## 수동 일정

일정명 위에서 할 일/마감일을 선택합니다. 할 일은 시작/종료, 마감일은 종료만 입력합니다.
상세 설정에는 작업 유형·예상 소요시간·우선순위·연결 마감일 등이 있고, 마감일 모드에는 소요시간을 요구하지 않습니다.
저장된 마감일과 고정 할 일은 자체 캘린더에 표시되며 유동 작업의 가능 기간을 자동 배치하지 않습니다.
Google 계정이 연결되어 있으면 등록·수정·삭제가 자동 반영됩니다.

## 문장으로 등록

수동 일정 등록 화면에서 문장 입력과 직접 입력을 함께 사용합니다. 이전 `/sources/new?mode=natural` 링크도 이 화면을 엽니다.
입력을 멈추면 자동으로 해석해 아래 항목을 채우며 미리보기 버튼은 없습니다. 직접 수정하면 진행 중인 해석을 취소합니다.
서버의 현재 한국 시간으로 내일·요일·다음 주를 읽고, 종료가 없으면1시간을 제안합니다.
마감 시간이 없으면23:59를 제안합니다. 종류/제목/시작·종료를 수정하고 기존 Task/Deadline API로 등록합니다.
문장 해석만으로 외부 AI 전송·원본 자료 생성·일정 저장·Google 전송을 하지 않습니다. 등록 버튼을 눌러 저장한 뒤에는 기존 Google 자동 반영을 따릅니다.
반복·복잡한 문장/누락값은 수동 확인이 필요합니다.
상세 계약과 지원 표현은 [백엔드 문서](../../backend/docs/natural-schedule.md)를 참고하세요.
