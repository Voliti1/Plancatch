# 마감일 검토 흐름

새 일정 저장 후 `/sources/[id]/review`에서 검토를 준비합니다. 원본 상세의 이력에서도 다시 열 수 있습니다.

1. URL은 공개 HTML을 추출하고 동일 공고의 구조화 정보/본문에서 날짜 후보를 읽습니다. Gemini나 URL의 이미지를 자동 호출하지 않습니다.
2. 원본 텍스트와 업로드 이미지는 외부 AI 전송 대상과 내용을 안내하고 동의받은 뒤 분석합니다.
3. `/analyses/[id]`에서 상태·자료 정보·짧은 근거·후보를 표시합니다. 이미지는 원본 미리보기를 제공합니다.
4. 입력한 일정 제목은 새 후보 제목으로 전달됩니다. 비워 두면 추출 제목을 사용하고 검토 중 다시 바꿀 수 있습니다.
5. 명시된 마감 시간을 유지하며, 날짜만 있으면 한국 시간23:59를 제안합니다. 불확실한 연도/날짜나 충돌은 임의 확정하지 않습니다.
6. 제목·마감일·설명·포함 여부를 수정한 뒤 저장하고 승인합니다. 수정 상태에서는 승인할 수 없습니다.
7. 승인은 마감일만 만들며 반복 승인 요청은 같은 결과를 반환합니다. 전체 거부는 마감일을 만들지 않습니다.

AI 신뢰도는 정확도 보장이 아닙니다. HTML과 공고 이미지의 시간도 다를 수 있으므로 원문을 확인해야 합니다.
기존 미수정 이미지 검토의 입증 가능한 잘못된 기본 시간은 수정 제안으로 보여주되, GET 조회로 DB를 바꾸지 않습니다.
이미 수정/승인된 결과를 새 정책으로 자동 덮어쓰지 않습니다.

## API

- POST /api/sources/{id}/analyze: URL/텍스트 원문 추출.
- POST /api/sources/{id}/ai-analyses: 유형에 맞는 HTML 또는 동의된 AI 분석. 현재 원문 hash와 재사용 옵션을 확인합니다.
- GET /api/sources/{id}/ai-analyses, GET /api/ai-analyses/{id}: 이력/상태 조회.
- PATCH /api/ai-analyses/{id}: revision과 전체 후보의 id/title/due_at/description/selected.
- POST /api/ai-analyses/{id}/approve 또는 /reject: 현재 revision으로 승인/거부.

근거와 신뢰도는 읽기 전용이며 원래 초/밀리초와 명시 시간대를 보존합니다.
401은 로그인 만료,404는 접근 불가,409는 원문/검토 충돌,422는 입력 오류입니다.
실패 시 작성 중인 검토를 유지하고 최신 내용을 불러올 때 사용자 입력을 버릴지 확인합니다.
브라우저 조회는 제한된 시간 동안만 자동 실행하며 화면 이탈 시 중단합니다. 이것이 서버 AI 작업 취소를 의미하지는 않습니다.

일반 `npm test`는 합성 자료/응답만 사용합니다. `npm run test:live`는 실제 DB·외부 AI를 사용할 수 있는 별도 검사입니다.
Task 생성·안전 마감 설정·역산 계획·자동 배치·Google 전송은 후보 승인과 별개입니다.
