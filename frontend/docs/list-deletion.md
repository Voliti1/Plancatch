# 원본 자료·마감일 목록 삭제 모드

등록 버튼 왼쪽의 ‘삭제 모드’는 빨간 테두리/흰 배경/빨간 글씨입니다.
누르면 ‘삭제 모드 해제’로 바뀌고 왼쪽에 같은 색의 ‘삭제’가 생깁니다.
현재 페이지 항목의 왼쪽에 체크 표시가 나타나며 항목 전체 클릭/Enter/Space로 선택·해제합니다.
선택 개수는 삭제 버튼 바로 왼쪽에 11pt(약14.67px) ‘0개 선택’으로 표시하며 별도 조작 설명 박스는 표시하지 않습니다.
이때 링크와 텍스트 펼치기 대신 선택만 동작합니다. 일반 모드에서는 원래 탐색 기능을 유지합니다.

선택 → 삭제 → 빨간 배경/흰 글씨 ‘삭제 확인’ → 실제 삭제 순서입니다.
선택 변경/모드 해제/페이지 변경 시 확인을 초기화합니다. 페이지 이동은 선택도 초기화합니다.
삭제 중에는 선택·버튼·페이지 이동을 잠그며 화면 이탈 시 남은 후속 삭제를 중단합니다.
이미 전송한 서버 삭제 요청까지 취소하거나 복구한다는 의미는 아닙니다.

기존 소유권 검사가 있는 DELETE API를 항목별로 순서대로 호출합니다. DB/API 구조 변경은 없습니다.
성공 항목만 선택에서 제거하고 목록을 새로 조회합니다. 부분 실패는 실패·미처리 항목의 선택을 유지합니다.
401/403/연결 오류는 이후 항목 요청을 중단하며, 동일 ID의404는 이미 삭제된 상태로 처리합니다.
응답 유실 재시도는 같은 항목 ID만 확인합니다. 한 번의 삭제가 전체 항목의 원자적 트랜잭션은 아닙니다.

마감일이 연결된 원본 자료는 서버에서409/source_has_deadlines로 삭제를 거부합니다.
마감일을 모두 삭제하거나 연결을 해제한 뒤에만 자료를 삭제할 수 있습니다.
삭제 가능한 원본 자료를 삭제하면 연결된 분석 기록도 삭제됩니다.
마감일 삭제 시 연결된 할 일은 유지되고 마감일 연결만 해제됩니다.
Google에 전송한 일정은 자동 삭제하지 않습니다. 전송 이력은 중복 방지를 위해 보존합니다.
확인 안내에 삭제 범위를 표시합니다. 코드/빌드 롤백으로 삭제된 사용자 데이터를 복원하지 않습니다.
