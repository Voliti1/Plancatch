# 자료 저장 후 바로 검토

‘새 일정 등록하기 → 자료로 등록 → 자료 저장’은 저장된 자료의
`/sources/{id}/review`로 이동합니다. 원본 자료 목록에서도 같은 등록 화면을 사용합니다.
URL은 추출·HTML 분석을 이어서 실행하고 기존 `/analyses/{id}` 검토 화면으로 이동합니다.
텍스트는 추출 후 Gemini 전송 동의를 한 번 받습니다. 동의는 저장하지 않으며 변경된 원문에는 재동의가 필요합니다.

날짜 승인과 Google 전송은 자동 실행하지 않습니다. 파일 업로드는 기존처럼 준비 중입니다.
90초간 원문 처리를 조회하며 오류/시간 초과 시 같은 자료의 ‘진행 상태 확인·다시 시도’를 사용합니다.
자료 재생성 없이 진행 중/기존 결과를 먼저 확인합니다. 분석 응답이 유실돼도 같은 원문 결과를 재사용합니다.
기존 실패 결과는 자동 재분석하지 않고 실패 검토 화면으로 연결합니다. 재분석은 자료 상세에서 명시적으로 실행합니다.
페이지를 떠나면 클라이언트 조회/후속 요청·자동 이동을 취소하며 이미 시작된 서버 작업은 취소하지 않습니다.

Backend의 SourceResponse에 extracted_text_hash가 추가됩니다. 분석 실행 API의 선택적
input_hash/reuse_existing은 원문 버전 검증/같은 원문 결과 재사용을 합니다. source 행 잠금 안에서 확인합니다.
기존 분석 API 호출과 자료 상세의 수동 재분석은 바뀌지 않습니다. DB migration/새 의존성은 없습니다.
