# 작성 중 입력 보호

자료 등록(URL·텍스트·이미지·PDF)·자료 수정, 수동/문장 일정 등록, 할 일 수정,
마감일·안전 마감·Google 알림 설정 수정, AI 후보 검토와 기존 배치 편집의
저장하지 않은 입력을 공통으로 추적합니다. 값 전체를 처음 상태로 되돌리면 경고도 해제합니다.

- 메뉴·취소 링크·새 일정 등록 재진입·로그아웃 전에 이동 여부를 확인합니다.
- 취소하면 현재 입력과 선택한 파일을 유지합니다. 동의하면 원래 이동 동작을 진행합니다.
- 자료/수동 등록 탭 전환은 입력을 유지하므로 확인하지 않습니다. 숨겨진 탭의 입력도
  페이지 전체를 떠날 때에는 보호합니다. 저장 성공은 선택한 등록 흐름을 완료합니다.
- 편집 취소 버튼은 변경분이 있을 때 확인합니다. 저장 성공 시 경고를 해제하며
  검증 오류·서버 오류·revision 충돌은 입력과 보호를 유지합니다.
- AI가 처음 제안한 값은 최초 화면 상태로 취급하고 사용자 수정분을 보호합니다.
  후보 자동 저장 후 승인만 실패한 경우에는 이미 저장된 버전을 기준으로 판단합니다.
- AI 후보 수정 저장 중 이동에 동의하면 클라이언트의 후속 승인을 중단합니다.
  이미 서버에 도착한 저장·승인 요청까지 취소되었다고 표시하지는 않습니다.

`beforeunload`는 수정분이 있을 때만 연결합니다. 새로고침·창 닫기의 경고 문구와
표시 여부는 브라우저가 결정합니다. 모바일 운영체제의 강제 종료까지 막을 수는 없습니다.

최근 브라우저의 Navigation API에서 실제 이력 위치를 읽어 동일 문서의 뒤로/앞으로
이동 취소 시 원래 위치를 복원합니다. Next의 이력 상태를 수정하거나 가짜 이력 항목을
추가하지 않습니다. 해당 API가 없는 구형 브라우저에서는 링크·로그아웃·새로고침 보호는
유지되지만 SPA 뒤로/앞으로 이동 취소를 보장하지 않습니다.

이 보호는 자동 저장 기능이 아닙니다. 원문·파일·검토 내용·동의 상태·인증 정보를
브라우저 저장소에 추가로 저장하지 않으며, API와 서버 처리는 변경하지 않습니다.
기존 URL 자동 등록의 재개 저장 방식은 유지합니다.

참고: [Next Link의 이동 차단](https://nextjs.org/docs/app/api-reference/components/link#blocking-navigation),
[Navigation 이벤트](https://developer.mozilla.org/en-US/docs/Web/API/Navigation/navigate_event).

검증은 합성 응답을 사용하는 PC·모바일 브라우저 검사로 수행합니다. 실제 사용자 자료를
AI에 보내거나 Google 캘린더에 쓰지 않습니다. 운영 배포 여부는 별도로 확인해야 합니다.
