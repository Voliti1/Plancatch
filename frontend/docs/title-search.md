# 원본 자료·마감일 제목 검색

등록/삭제 버튼 아래 제목 검색창에서 입력을 멈춘 뒤300ms 후 자동 검색합니다.
검색 버튼 또는 Enter는 즉시 적용하고 한국어 조합 중에는 요청하지 않습니다.
서버가 로그인 사용자 전체 자료의 제목을 먼저 필터링한 뒤 기존 정렬/50개 페이지를 적용합니다.
앞뒤 공백을 제거하며 빈 검색은 전체 목록입니다. 대소문자를 구분하지 않는 부분 일치이고,
%, _, /, 정규식·HTML 문자는 일반 글자로 처리합니다. 제목 일치 부분은 노란색으로 강조합니다.
원문/설명은 검색 대상이 아니며 초성/오타 교정 검색은 지원하지 않습니다.

검색어가 바뀌면1페이지로 돌아가 삭제 선택/확인을 초기화하고, 실제 삭제 중에는 검색을 잠급니다.
이전 요청이 늦게 와도 새 결과를 덮지 않으며 결과 제목 강조는 적용된 검색어를 사용합니다.
검색 결과가 없으면 별도 안내를 표시합니다. 기존 로그인/삭제 보호/Google 전송 동작은 유지합니다.
GET /api/sources 및 /api/deadlines의 선택 q(최대255자) 외 API 응답/DB 구조 변경은 없습니다.
