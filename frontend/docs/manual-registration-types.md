# 수동 등록 종류 및 동일 너비

- 자료/수동 등록 카드는 동일한 최대 너비1100px, 좁은 화면에서는100%로 줄어든다.
- 안내 문구 다음, 일정명 위에서 ‘할 일 / 마감일’ 버튼을 선택한다. 기본은 기존과 동일한 할 일이다.
- 할 일은 기존 제목·시작/종료·메모·상세 설정(소요시간/우선순위/유형/연결마감/완료)을 유지한다.
- 마감일은 제목·종료 일시·메모만 표시하고 Task 전용 시작/소요시간/상세 설정은 숨긴다.
- 종류를 바꿔도 입력값은 유지하되, 마감일 제출은 숨겨진 Task 필드를 검사하거나 전송하지 않는다.
- 할 일은 기존 POST /api/tasks, 마감일은 기존 POST /api/deadlines에 due_at=종료 일시로 저장한다.
  직접 입력한 마감은 is_confirmed=true, source_id/안전버퍼/유형은 null이다. 안전 마감 설정은 마감 상세에서 할 수 있다.
- 등록 성공 후 해당 Task/Deadline 상세로 이동하며 기존 캘린더 표시 계약을 따른다. Google에 전송하지 않는다.
- 저장 중 종류/상위탭 변경을 잠그고 오류 시 입력을 유지한다. 새 등록 화면을 열면 이전 저장 응답이 이동시키지 않는다.
- DB/API 변경 없이 프론트 화면과 기존 API 호출만 조정했다. 수정 화면에서 기존 데이터의 종류 변환은 지원하지 않는다.
