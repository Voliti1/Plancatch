# 이미지로 일정 등록

새 일정 등록→자료로 등록→파일로 추가에서 PNG/JPG/WebP/BMP/GIF/TIFF/AVIF 한 장(최대5MB)을 선택한다.
PNG의 MIME 별칭이나 빈 MIME 때문에 차단하지 않으며 실제 파일은 서버에서 검증한다.
PNG로 변환해 저장·분석하고 투명 배경은 흰색으로 채운다. 한 장의 정지 이미지만 지원한다.
URL/텍스트와 동시에 저장할 수 없으며, 애니메이션·다중 프레임 이미지·HEIC·SVG는 지원하지 않는다. PDF는 같은 파일 입력에서 별도로 처리한다.
이미지 저장→원본 미리 보기·Gemini 전송 동의→분석→기존 마감일 검토 화면으로 연결한다.
이미지 저장만으로 외부AI가 호출되거나 일정이 자동 등록되지 않는다.

이미지 검토에는 인증으로 읽은 원본 미리 보기와 짧은 근거/읽은 날짜 선택지가 표시된다.
날짜가 확정되고 시각만 없으면 한국 시간23:59를 제안하고 안내를 표시한다. 원문에 시각이 있으면 그 시각을 유지한다.
연도·날짜가 불명확하거나 원문 날짜가 충돌하면 직접 확인하도록 남겨 둔다.
사용자가 제목·마감 일시와 후보 선택을 확인하고 ‘선택한 N개 일정 등록’을 눌러야 마감일이 생성된다.
수정 내용은 등록 시 먼저 저장한다. ‘검토 내용 저장’만으로는 마감일이 생성되지 않는다.
후보는 기본 미선택이며 추천공고/자격요건의 날짜는 제외하도록 분석한다.
AI/OCR이 틀릴 수 있으므로 이미지와 결과를 직접 비교한다.

동일한 이미지의 처리 중/완료 결과는 재사용해 새로고침으로 외부 호출을 반복하지 않는다.
실패 결과는 자동 재분석하지 않으며 다시 검토 화면에서 동의한 뒤 요청한다.
이미지는 외부 공개주소가 아니며 로그인한 소유자만 미리 볼 수 있다. 화면 이탈 시 Blob URL을 해제한다.
기존 URL은 HTML 직접 추출/텍스트는 원문 전송 동의 흐름을 유지한다.

PDF는 5MB 이하 한 파일을 저장한 뒤 텍스트를 직접 읽는다. 스캔 전사가 필요할 때 원본의 Gemini 전송 동의를 확인한다.
검토 화면에는 문서의 공고 제목·회사명·후보별 날짜와 근거를 표시하며, 확인되지 않은 회사명은 확정해서 표시하지 않는다.
연도가 생략된 마감일은 같은 PDF의 명확한 공고 연도로 보완할 수 있지만, 여러 연도가 충돌하면 확정하지 않는다.
이전 PDF 결과도 검토할 수 있다. 다시 분석할 때도 텍스트를 먼저 확인하며, 스캔 전송 동의는 계정과 브라우저별로 저장할 수 있다.
