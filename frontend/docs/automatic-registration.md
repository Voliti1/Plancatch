# 대시보드 자동 일정 등록

대시보드의 **새 일정 등록하기** → `/deadlines/auto`에서 **자동 일정 등록** 화면을 연다.
원본 자료 페이지의 **자료 등록**, `/sources/new`의 수동 URL/텍스트 저장은 변경하지 않는다.

필수 일정 제목·공개 URL과 Gemini 전송/자동 등록 동의를 입력한 후 **일정 등록**을 누르면:

1. 입력한 제목으로 URL Source 저장.
2. 기존 analyze API로 원문 추출 및 제한된 상태 조회.
3. 추출된 전체 텍스트를 동의한 Gemini 분석 API에 전송 및 상태 조회.
4. `POST /api/ai-analyses/{id}/auto-register`로 입력 제목의 확정 마감일 생성.
5. 성공 시 생성된 마감일 상세로 이동.

자동 등록 본문: `revision`, `title`, `confirm_auto_registration: true`.
원본 제목과 요청 제목 일치, 소유권, 원문 해시/상태, revision 검증을 수행한다.
수정되지 않은 revision 1의 단일 선택 후보이며 명시적 날짜가 있고 AI warnings가 없을 때만 자동 등록한다.
여러 후보·날짜 없음·주의사항·수동 수정 결과는 422 `auto_registration_requires_review`로 거부하고
마감일을 만들지 않는다. 화면에 검토 안내와 기존 AI 검토 화면 링크를 표시한다.
AI 신뢰도 값은 정확도를 보장하지 않으며 사용자가 원문과 추출 날짜를 확인해야 한다.

제목 변경과 마감일 생성은 기존 분석 행 잠금/동일 트랜잭션에서 처리한다.
이미 approved인 요청의 재시도는 같은 ID를 반환하고 마감일을 중복 생성하지 않는다.
안전 여유시간은 미설정으로 생성되며 작업·일정 블록 자동 배치·Google Calendar 동기화는 수행하지 않는다.
DB 구조 변경은 없다.

요청은 15초 제한, 각 처리 상태 조회는 2초 간격/최대 90초/한 요청씩이다.
페이지 이탈 시 조회를 취소하지만 서버의 기존 background 작업을 취소하지 않는다.
같은 탭의 사용자 ID별 sessionStorage에 제목·URL·Source/Analysis ID만 보관한다.
토큰·비밀번호·원문은 추가로 저장하지 않는다. 새로고침 후 명시적 동의를 다시 받아 이어서 처리한다.
실패/응답 유실 시 이미 생성한 Source 및 최신 Analysis를 재사용한다.
실패한 AI 분석을 다시 요청하는 경우 별도 Gemini 호출 비용이 발생할 수 있다.
**다른 일정 입력**은 화면의 재개 기록만 지우며 서버 자료를 삭제하지 않는다.

로그인 필요/접근 거부/수집 정책 거부/JS 페이지/과대 원문/AI 실패는 설명하고 자동 마감일을 만들지 않는다.
운영 코드에는 mock이 없으며 합성 브라우저 테스트는 별도 테스트 계층만 사용한다.
`backend/tests/fixtures/automatic-deadline.txt`는 실제 URL→Gemini→등록 검증용 공개 합성 자료다.
