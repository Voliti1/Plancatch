# 캡처 이미지 붙여넣기

- 새 일정 등록 → 자료로 등록 화면에서 캡처를 클립보드에 복사한 뒤 Ctrl+V를 누르면 파일로 추가에 한 장이 선택된다.
  제목/URL/텍스트 입력칸에 초점이 있어도 이미지 붙여넣기를 처리한다. 기존 입력 내용은 지우지 않는다.
- 실제 paste 이벤트의 이미지 File만 사용한다. 페이지 진입 시 클립보드를 읽거나 별도 읽기 권한을 요청하지 않는다.
  이미지가 없는 일반 URL/텍스트 붙여넣기는 기본 동작을 유지한다. 수동 등록 탭, 저장 중, 다른 페이지에서는 처리하지 않는다.
- 드래그/파일 선택과 동일하게 한 장·5MiB·기존 지원 형식을 검사한다. 이름 없는 PNG 등의 클립보드 이미지는
  형식에 맞는 파일명을 붙인다. 서버의 실제 파일 형식 판별과 PNG 변환을 우회하지 않는다.
- 사진을 다시 붙이면 선택을 교체하며 제거 버튼으로 취소할 수 있다. 잘못된 입력은 기존 선택을 덮지 않는다.
  URL/텍스트와 이미지를 동시에 작성해 두면 기존의 한 종류만 저장하는 안내를 따른다.
- 붙여넣기는 브라우저 내 파일 선택까지만 수행한다. 자료 저장을 누르기 전 업로드하지 않고,
  저장 후 기존 이미지 검토 화면의 외부 AI 전송 동의를 유지한다.
- Playwright는 합성 DataTransfer/ClipboardEvent로 검사한다. 사용자 운영체제 클립보드를 읽거나 덮지 않는다.
