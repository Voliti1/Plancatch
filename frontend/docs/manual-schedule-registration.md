# 수동 일정 등록

자료 입력과 수동 일정 등록 두 탭으로 구성합니다. 이전 `mode=natural` 링크는 수동 일정 등록 화면을 엽니다.
수동 화면에는 문장 입력과 직접 수정할 수 있는 일정 항목을 항상 함께 표시합니다.
문장 입력을 600ms 멈추면 기존 `/api/schedules/interpret`에서 해석하고 항목을 채웁니다.
한글 조합 중에는 요청하지 않으며 새 문장, 화면 이동, 직접 항목 수정 시 이전 요청을 취소합니다.
늦게 도착한 해석 결과는 직접 입력한 값을 덮어쓰지 않습니다. 실제 저장은 등록 버튼으로만 수행합니다.

일정 상세에서는 캘린더 배치 화면과 해당 화면을 위한 요청을 제거했습니다.
`task-placements.tsx`와 백엔드 scheduled-events API·데이터·검증은 향후 재사용할 수 있도록 보존했습니다.
기존 배치의 캘린더 조회 및 Google 동기화가 사용하므로 백엔드는 비활성화하지 않습니다.
