# PlanCatch 캘린더

## 등록 결과 표시

‘새 일정 등록하기’의 자료 분석·승인으로 저장한 마감일과 수동 등록한 고정 일정을 캘린더에 표시합니다. 이미 저장된 항목에도 적용되며 별도의 캘린더 등록 버튼이나 배치 단계는 필요하지 않습니다.

- 자료 기반 마감일: 승인 등으로 Deadline이 저장된 뒤 공식 due_at 날짜에 표시합니다. 자료만 저장하거나 AI 후보만 있는 상태는 표시하지 않습니다.
- 수동 고정 일정: Task의 시작·종료가 모두 있을 때 해당 구간에 표시합니다. 유동 작업의 가능 기간이나 날짜 없는 Task를 임의로 배치하지 않습니다.
- 별도 ScheduledEvent가 있는 Task는 등록 일정 투영에서 제외합니다. 취소한 배치도 포함하여 원래 고정 시간이 중복/재등장하지 않도록 합니다.
- 등록 일정의 제목·날짜 수정 및 삭제는 기존 Task/Deadline API를 통해 이루어지며 다음 조회에 반영됩니다. 이 기능이 새 배치 행을 만들지는 않습니다.

`GET /api/calendar/registrations`는 본인의 날짜 범위(62일 이하)만 조회하며 종류별1,000건 초과를 표시합니다. 오류를 빈 캘린더로 숨기지 않고 재시도 버튼을 제공합니다.

## 월/주 화면

- 한국 시간 기준 월간42칸·주간7칸, 이전/다음 기간·오늘·기준 날짜 이동.
- 날짜 칸에 흰색 제목을 가진 색상 바를 표시합니다. 마감일 분홍, 수동 일정 파랑, 실제 배치 보라, 구글 초록, 취소 회색입니다.
- 칸당3개와 나머지 개수를 표시하며 날짜를 선택하면 아래 목록에서 전체 항목을20건씩 확인할 수 있습니다. 긴 제목은 말줄임/마우스 제목 안내와 상세 목록을 사용합니다.
- 마감일은 정확한 시점이 속한 날짜에 표시하고 시간 구간의 종료 자정은 다음 날에 포함하지 않습니다.
- 날짜별 ‘상세·수정’ 링크는 기존 마감일/작업 화면을 엽니다. 그 화면에서 변경한 내용이 다음 조회에 반영됩니다.

## 기존 수동 배치

일정 상세의 캘린더 배치에서 기존 Task를 원하는 시간으로 별도 배치하거나 수정·삭제할 수 있습니다. 배치와 Task의 가능 기간은 독립적이며 배치 삭제로 Task 자체를 삭제하지 않습니다. 원래 가능 기간을 자동으로 다시 배치하지는 않습니다.

기존 /api/scheduled-events는100건씩 최대20페이지를 읽습니다. 제한에 닿으면 범위를 줄이도록 안내합니다. task_title을 함께 반환하여 각 제목의 개별 API 요청을 줄였습니다. 취소는 기본 숨김이며 동기화된 배치 변경은 제한합니다. 저장 응답을 확인하지 못한 경우 기존 배치 폼은 재제출을 잠가 중복을 방지합니다.

## 구글 기본 캘린더

‘구글 일정 함께 보기’는 기본 꺼짐이며 사용자가 켜야 본인 기본 캘린더를 읽습니다. 한국 시간·종일 일정의 종료일 제외, 같은 구글ID/시각의 내부 배치 중복 방지, 같은 기간 재조회 캐시를 유지합니다. 오류/250건 제한/제외된 형식은 안내하고 개인 일정은 변경하지 않습니다.

## 검증 범위와 후속 작업

현재 기능 검증은 PR 및 checkpoints/PRS.md와 current-deployment.md의 실제 실행 결과를 기준으로 합니다. 가상 응답의 UI 검사와 임시 계정으로 실제 서버 API를 점검한 결과를 구분합니다. 비밀번호·토큰은 출력하거나 trace/HAR/Git에 저장하지 않습니다.

자동 배치·재배치·충돌 검사·역산 계획, 구글 등록/수정/삭제 전송·양방향 동기화, 내부 반복/종일 일정 생성과 드래그 변경, PDF/JPG 추출은 후속 범위입니다.
