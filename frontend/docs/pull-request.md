# PR 제목

feat(frontend): add source details and deadline-linked task management

# 변경 내용

원본 자료를 목록에서 확인한 뒤 상세 조회·수정·삭제할 수 있도록 하고, 마감일을 준비할 작업을 직접 등록하고 관리할 수 있도록 합니다. 기존 Source API와 저장소의 Task CRUD 계약을 연결합니다.

- `/sources/[id]`: 제목·URL/텍스트 수정, 취소, 삭제 확인, 처리 상태와 한국 시간 표시
- `/tasks`, `/tasks/new`, `/tasks/[id]`: 목록·등록·상세·수정·삭제, 완료·미완료 전환
- 마감일 상세의 연결된 작업 목록과 마감일을 미리 선택한 등록 화면
- 소요시간·우선순위 숫자·고정/유동 유형·가능 기간, 완료/유형 필터와 페이지 이동
- 오류 시 입력 보존, 재시도, 401·404·삭제 409 처리, PC·모바일 반응형 UI
- 선택한 날짜가 그대로면 초·밀리초 보존, 한국 시간 입력을 UTC로 전송

API·타입·화면을 분리했으며 백엔드와 인프라 파일은 변경하지 않습니다.

- 미국 시간대 브라우저에서도 한국 시간 변환·날짜 정밀도 검증

# 연동 시 확인할 사항

테스트는 브라우저 요청을 가로채는 테스트 전용 응답을 사용합니다. 실제 EC2 API 배포 여부와 데이터 영구 저장은 별도 확인해야 합니다. 운영 화면은 mock을 사용하지 않으며 `NEXT_PUBLIC_API_BASE_URL`을 통해 API를 호출합니다.

AI 분석·역산 작업 계획·자동 일정 배치·Google Calendar 연결은 아직 구현하지 않았습니다. 고정/유동 유형을 저장해도 캘린더 배치는 수행하지 않습니다.

대상: `feature/frontend-base` → `main`
