feat(frontend): connect source extraction and AI deadline review

# 변경 내용

자료 상세에서 원문 추출과 AI 분석을 요청하고, 원문·근거를 비교해 마감일 후보를 수정·제외한 뒤 승인 또는 전체 거부할 수 있도록 합니다. 승인한 후보만 실제 마감일로 생성되며 Task·일정 배치·Google Calendar 동기화는 수행하지 않습니다.

- 추출 상태와 AI 상태 분리, 요청 잠금, 2초 간격·최대 90초의 상태 조회와 중단/재시도
- 원문 전체의 Google Gemini 전송 동의, 40,000자 한도, 내용 변경 시 동의 갱신
- `/analyses/[id]`: 원문 스냅샷·주의사항·근거·참고 신뢰도와 후보 검토
- 현재 revision과 전체 후보의 수정 가능 필드만 전송, 성공 후 새 revision 적용
- 저장·승인 오류 시 입력 보존, 충돌 시 명시적 최신 결과 조회, 원문 변경 시 재분석 안내
- 승인된 마감일 링크, 거부 확인, 분석 기록의 페이지 이동, PC·모바일 UI

API·타입·화면을 분리했으며 백엔드와 인프라 파일은 변경하지 않습니다.

- 별도 실제 서버 검증 2개: 전용 계정으로 URL/텍스트 추출, 실제 Gemini 분석·수정·승인, 새로고침 후 저장 유지 및 중복 승인 방지
- 생성한 테스트 자료 6개·마감일 2개 삭제 확인. 계정 삭제 API가 없어 전용 계정 2개는 남음

# 연동 시 확인할 사항

기본 테스트는 합성 응답만 사용하고 `test:live`는 명시적인 공개 API 주소로 실제 서버에 연결합니다. 실제 비밀번호·토큰을 출력하거나 trace에 기록하지 않습니다. API 키는 백엔드에만 있으며 프론트엔드에는 추가 비밀 환경변수가 없습니다. 운영 화면은 mock을 사용하지 않고 기존 같은 origin의 `/api` 연결과 Bearer 인증을 유지합니다.

역산 작업 계획·안전 마감일·자동 일정 배치·Google Calendar 연결은 아직 구현하지 않았습니다. 브라우저 대기 중단은 서버 작업 취소가 아니며 재시작 후 영구 대기 작업의 복구는 백엔드 후속 과제입니다. 새 화면의 EC2 배포는 이번 작업에 포함하지 않습니다.

대상: `codex/frontend-ai-review` → `integration/frontend-tasks-live-ai`
