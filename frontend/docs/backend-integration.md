# 백엔드 연동 현황

현재 지원 범위는 [프론트엔드 README](../README.md), [저장소 개요](../../README.md),
[2026-11-02 통합 범위](../../backend/docs/main-integration-20261102.md)를 기준으로 합니다.

인증·비밀번호 변경, 원본 자료, 공개 URL HTML, 이미지/텍스트 AI 검토, 후보 수정·승인·거부,
마감일·안전 마감일, 할 일 CRUD와 수동 배치, 자체 캘린더, Google 계정 연결·조회·명시적 전송을 연결했습니다.
문장으로 등록은 인증된 `/api/schedules/interpret` 미리보기 후 기존 Task/Deadline 등록을 사용합니다.
제목 검색/선택 삭제/연결 원본 보호/마지막 마감일의 원본 정리와 다크 모드도 포함합니다.

## 경계

- URL은 HTML 직접 추출이며 이미지/텍스트의 외부 AI 동의와 구분합니다.
- 후보 승인은 마감일만 만듭니다. 할 일·역산 계획·자동 배치·Google 전송을 자동 실행하지 않습니다.
- Task 가능 기간과 실제 ScheduledEvent 배치는 별도입니다.
- Google 전송은 preview/confirm 계약과 고정 전송 ID로 중복을 막습니다. 수정/삭제의 자동 동기화는 후속입니다.
- PDF·역산 계획·작업 의존 관계·자동 배치/재배치·위험도는 미구현입니다.

## 검증

일반 검사는 SQLite/합성 HTML·이미지·외부 응답과 브라우저 API 가로채기를 사용합니다.
PostgreSQL 구조/동시성 검사와 실제 서버 전용 계정 검사는 별도로 기록합니다.
개인 Google 일정 쓰기나 사용자 캡처의 AI 재전송을 합성 검사로 검증했다고 표현하지 않습니다.
운영 반영과 Git 병합은 별개이며 `checkpoints/PRS.md`와 `current-deployment.md`에 실제 SHA/빌드를 대조합니다.
