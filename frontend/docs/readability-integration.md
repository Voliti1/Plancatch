# 가독성·카드 폭 통합

팀원 PR #87의 일정 상세 카드 폭 정리와 PR #88의 글자·입력창·버튼 크기 개선을 PR #89의 최신 등록·캘린더 화면 위에 적용했습니다.
원래 두 커밋의 작성자 기록은 유지합니다. 본문은 PC 17px, 모바일 16px이며 주요 설명과 입력 요소도 함께 커집니다.
가독성 스타일이 적용된 상세 카드와 Google 자동 반영·삭제 카드는 같은 최대 폭 920px를 사용합니다.

전체 버튼 크기 규칙에서는 월간 날짜 칸·시간표 날짜·설정 아이콘·원문 창 닫기·짧은 문장 예시를 제외합니다.
해당 요소는 원래 화면 구조에 맞춘 크기를 유지합니다. 일정 목록 아이콘은 35px를 유지하고 캘린더 보기 버튼 간격은 8px입니다.
320px 화면에서 월간 칸이 줄어들거나 보기 버튼이 화면 밖으로 나가지 않도록 조정했습니다.
문장 입력 영역은 미리보기 버튼 없이 수동 입력란과 함께 보이며, 기존 요청 취소·직접 수정 우선·명시적 등록 동작은 유지합니다.

이 변경은 화면 스타일만 바꾸며 API·DB·Google 권한이나 전송 정책은 바꾸지 않습니다.
