# 일정 목록과 시간표

왼쪽 ‘일정’과 `/deadlines` 화면에서 마감일·할 일을 함께 조회한다.
‘일정 목록’ 옆 체크박스는 둘 다 선택되어 시작한다. 선택하면 파란 바탕·흰 글씨,
해제하면 중립색이다. 제목 검색은 입력 변화에 따라 적용되고 일치 문구를 강조한다.
필터·검색·페이지 이동 시 삭제 선택과 확인 상태를 초기화한다.
혼합 목록의 삭제는 기존 종류별 API를 호출하며 기존 삭제 보호 규칙을 유지한다.
할 일의 가능 기간은 실제 캘린더 배치 시간과 다를 수 있음을 표시한다.

일정 목록 상단 ‘일정 등록’은 왼쪽 ‘새 일정 등록하기’와 같은 공유 등록 화면으로 이동한다.
목록 내부의 별도 등록 폼은 제거했다. 다시 열면 이전 입력이 남지 않도록 새 화면으로 시작한다.
원본 자료 목록에는 별도 자료 등록 버튼을 두지 않으며 기존 조회·검색·삭제는 유지한다.
안전 마감일은 등록한 마감일의 상세 화면에서 설정할 수 있다.

캘린더는 다음 세 가지 보기를 제공한다.

- 월간: 기존 날짜 격자와 색깔 막대.
- 오늘: 한국 시간의 오늘로 이동하고 00:00~24:00 하루 시간표를 표시한다.
  제목에 전체 날짜를 표시하며 이전·다음으로 하루씩 이동한다.
- 주간: 선택일이 속한 월요일~일요일의 7열 시간표. 이전·다음은 7일씩 이동한다.

하루·주간에 월간 날짜 격자를 함께 표시하지 않는다. 일정은 실제 시간 위치에 표시하고
겹치면 나란히 배치한다. 자정을 넘는 일정은 날짜별로 나누어 표시하며
매우 짧은 일정과 마감일은 읽을 수 있는 최소 높이로 표시한다. 실제 시각은 글자와 툴팁으로 확인한다.
Google 종일 일정은 상단 별도 행이다. 외부 Google 일정은 조회 전용이다.

빈 시간대 클릭은 기존 수동 등록 화면에 1시간의 시작·종료를 채운다.
23시를 누르면 다음 날 0시까지이며, 저장 전에는 아무 일정도 생성하지 않는다.
날짜 입력은 명시적 UTC ISO 형식만 허용하고 잘못된 값은 무시한다.

마감일은 분홍색, 할 일은 파란색과 흰 글씨로 통일한다.
수동 등록·확정 배치·연동 여부로 다른 색을 부여하지 않는다. 취소는 취소선으로 구분한다.
목록·일간 상세의 종류 배지도 밝은/어두운 화면에서 같은 색을 사용한다.
로컬 일정의 상세 링크 문구는 ‘상세, 수정’으로 통일한다.

작은 화면에서는 주간 시간표 안에서 가로·세로로 스크롤하고 페이지 전체가 가로로 늘어나지 않는다.
새 캘린더 라이브러리나 DB 필드를 추가하지 않는다. Google 자동 반영은 기존 저장 API 경로를 사용한다.

## 후보를 한 번에 일정으로 등록

‘선택한 N개 일정 등록’은 수정한 내용이 있으면 먼저 저장하고,
서버가 돌려준 최신 저장 버전으로 승인을 이어 처리한다. 수정하지 않았으면 바로 승인한다.
‘검토 내용 저장’은 검토를 나중에 이어가고 싶을 때 쓰는 별도 선택 사항이다.
저장 실패/다른 화면의 수정 충돌이면 승인하지 않고 입력을 유지한다.
저장 성공 뒤 승인 실패는 확인된 저장 버전을 유지하여 재시도 시 중복 저장하지 않는다.
응답을 받지 못한 승인의 재시도는 기존 서버의 중복 등록 방지를 사용한다.
저장 대기 중 페이지를 떠나면 뒤이어 승인하지 않는다. 이미 서버에 도착한 승인 요청은
창을 닫는 것만으로 취소를 보장하지 않으므로 다시 열어 등록 결과를 확인한다.
할 일 목록에는 기존 색상을 따라 단일 앞면의 SVG 체크 목록 아이콘을 표시한다.
일정 목록의 할 일 SVG와 마감일 문자 크기는 모두35px이며, 모바일에서도40×43px 배경 안에 표시한다.
캘린더 보기 버튼은 같은 그룹 안에 오늘→주간→월간 순서로 놓고 간격은 모두8px다.
