## 통합하면서 정리한 항목

- 작성 중인 등록 화면을 명시적으로 버리는 기존 검사 다섯 곳에서 이탈 확인에 동의하도록 했다. 공통 자동 동의 처리는 사용하지 않는다.
- 회사명·마감일 파서 검사는 새로 추가된 PDF 제목·출처 필드와 공존하면서 기존 회사명·마감일 값도 계속 확인한다.
- 문서의 PDF 미지원 표기, 이미지 마감 시간 처리 및 별도 저장 후 승인 설명을 현재 기능과 맞췄다.
- 현재 화면 선택자에 맞는 별도 실제 API 통합 검사 `live-tests/integration-flow.spec.ts`를 추가했다. 과거 실제 서버 검사 파일 전체를 통과했다고 표현하지 않는다.

## 실제 서버 검사

운영 주소의 `/`와 `/health`가 각각200을 반환했다. 공개 OpenAPI 문서는404였으므로 실제 인증 요청과 화면 동작으로 계약을 확인했다.
운영 코드의 배포 SHA는 이 검사만으로 확인하지 않았다.

통합된 로컬 프론트엔드를 전달받은 운영 API에 연결해 PC·모바일 **2개 전체 흐름 검사를 통과**했다.
이 결과는 운영 프론트엔드가 새 통합 브랜치로 배포됐다는 뜻은 아니다.

| 실제 API/화면 동작                             | 결과                                                              |
| ---------------------------------------------- | ----------------------------------------------------------------- |
| 전용 계정 회원가입·로그인·로그아웃·보호 페이지 | PC·모바일 통과, 로그아웃 후 로컬 토큰 제거 확인                   |
| 텍스트 원문 전송 동의 및 AI 분석               | 동의 전 분석 요청 없음, 동의 후 실제 결과 확인                    |
| 후보 수정·선택·승인                            | 수정한 제목과 한국 시간 마감일 저장                               |
| 승인 재요청·새로고침·상세 수정                 | 같은 마감일 ID 유지, 중복 없음, 다시 읽은 날짜 동일               |
| PDF 업로드·전송 동의·AI 분석·전체 거부         | 실제 한 페이지 합성 PDF 처리, 거부로 마감일 생성 없음             |
| 공개 URL 추출·접근 제한 URL                    | 공개 본문 추출 성공, 사설 주소 오류 안내 확인                     |
| 수동 일정 등록 및 캘린더 표시                  | 저장 후 새로고침 유지, 승인 마감일과 고정 할 일이 캘린더에 표시됨 |
| Google 연결 전 상태                            | `not_connected`와 연결 전 안내 확인, Google에 실제 쓰기 없음      |
| 모바일 화면                                    | 가로 넘침 없음                                                    |
| 테스트 자료 정리                               | 이번 실행에서 만든 자료·마감일·할 일만 삭제, 전용 계정2개는 남음  |

재실행은 `frontend`에서 실제 테스트 대상 주소를 `PLANCATCH_LIVE_API_URL`에 명시한 다음 수행한다.
주소·계정·키를 소스나 공개 환경변수에 저장하지 않는다.

```text
npm run test:live -- integration-flow.spec.ts --max-failures 1
```

이 검사는 실행마다 `[테스트]` 전용 계정을 만들고 합성 자료만 사용한다. 토큰과 비밀번호를 출력하지 않으며
trace·동영상·스크린샷 기록을 끈다. 실행 중 생성한 ID만 추적해 자료·마감일·할 일을 정리한다.
계정 삭제 API는 없으므로 전용 테스트 계정 자체는 남는다. 다른 사용자의 자료나 Google 계정에 접근하지 않는다.

## 확인 범위의 한계

- 일반 검사에서 Google 성공/실패/재시도는 합성 응답이다. 실제 Google OAuth 및 개인 캘린더 쓰기 검증을 대신하지 않는다.
- 원문 추출과 외부 AI 분석은 별도 상태다. PDF·이미지·텍스트는 동의 전 분석하지 않으며, 승인 전 마감일을 만들지 않는다.
- 후보 승인은 할 일·역산 계획·자동 배치를 만들지 않는다. Google 연결 시 새 마감일의 서버 자동 반영 상태를 따로 확인한다.
- Git 통합·실제 API 연동 확인·운영 프론트엔드 배포는 별개다. 이번 작업으로 배포나 `main` 병합을 수행하지 않는다.
- 뒤로/앞으로 이동 보호는 Navigation API가 없는 구형 브라우저에서 제한된다. 모바일 운영체제 강제 종료까지 보장하지 않는다.
