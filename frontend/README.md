# PlanCatch 프론트엔드

Next.js App Router · TypeScript 기반 MVP입니다. 백엔드 코드 및 배포 설정은 변경하지 않습니다.

## 실행

Node.js 20.9 이상과 npm이 필요합니다. 저장소를 클론한 위치에서 `frontend`로 이동합니다.

```sh
npm ci
```

프론트엔드와 백엔드가 같은 origin이면 `NEXT_PUBLIC_API_BASE_URL`을 비워 두고 `/api`로 연결합니다. 별도 API를 사용하는 로컬 개발에서는 `.env.example`을 `.env.local`로 복사해 백엔드 기본 주소를 설정합니다. 값에 `/api`를 붙이지 않습니다. 브라우저에 공개되는 주소이므로 비밀정보를 넣지 않습니다. `.env.local`은 Git에서 제외됩니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 환경변수를 변경하면 개발 서버를 다시 시작합니다. 배포용 빌드에서는 빌드 전에 주소를 설정해야 합니다.

## 화면과 API

| 화면              | 동작                                                 |
| ----------------- | ---------------------------------------------------- |
| `/signup`         | JSON 회원가입, 비밀번호 확인, 성공 후 로그인 안내    |
| `/login`          | JSON 로그인, `/api/auth/me`로 사용자 검증            |
| `/dashboard`      | 사용자 이름, 자료·마감 요약, 마감일 목록             |
| `/sources`        | 자료 목록, URL 열기, 원본 텍스트 펼치기, 페이지 이동 |
| `/sources/new`    | URL 또는 텍스트 원본 자료 저장                       |
| `/sources/[id]`   | 자료 관리, 원문 추출·AI 전송 동의·분석 시작·기록     |
| `/analyses/[id]`  | 원문·근거 비교, 후보 수정·제외·승인·전체 거부        |
| `/deadlines`      | 마감 목록, 생성, 페이지 이동                         |
| `/deadlines/[id]` | 상세·수정·삭제 확인, 분석 근거와 연결된 작업 목록    |
| `/tasks`          | 작업 목록, 완료·유형 필터, 페이지 이동, 완료 처리    |
| `/tasks/new`      | 마감일 연결, 소요시간·우선순위·유형·가능 기간 입력   |
| `/tasks/[id]`     | 작업 상세·수정·삭제 확인, 완료·미완료 전환           |

모든 업무 화면은 인증 초기화와 사용자 조회가 끝나기 전까지 내용을 표시하지 않습니다. 토큰은 `sessionStorage`에만 보관하며 인증 요청에 Bearer 헤더를 붙입니다. 로그아웃 및 인증 API의 401 응답 시 토큰과 사용자 상태를 제거합니다. 프론트엔드의 접근 제한과 별개로 데이터 접근 권한은 백엔드가 검증해야 합니다. sessionStorage 방식은 MVP 범위이며 추후 HttpOnly 쿠키 기반 인증 전환을 검토할 수 있습니다.

목록 API의 `limit=50`, `offset`을 사용합니다. 대시보드 수치는 첫 50건 기준이며 50건이면 `50+`로 표시합니다. 원본 자료 연결 값과 분석 근거는 수정 과정에서 보존합니다. 마감 생성 시 원본 연결은 이번 화면 범위에 포함하지 않습니다.

날짜 표시는 `Asia/Seoul`입니다. 마감 입력도 브라우저/PC의 시간대와 관계없이 한국 시간으로 해석하여 UTC ISO 8601로 전송합니다.

원본 자료 목록의 **상세 보기**에서 제목, 원본 URL/텍스트, 처리 상태, 등록·수정 일시와 서버가 반환한 추출 내용을 확인할 수 있습니다. **자료 수정**으로 URL 또는 텍스트 자료를 수정하고 취소할 수 있으며, 빈 제목은 `null`로 전송합니다. 수정 시 자료 유형은 유지하고 해당 유형의 원본 필드만 전송합니다. URL은 HTTP/HTTPS만 허용하고 빈 텍스트는 거부합니다. 저장 오류가 발생하면 입력값을 유지합니다.

**자료 삭제**는 확인 후 DELETE API를 호출하며 성공하면 목록으로 이동합니다. 현재 백엔드의 외래 키 정책에 따라 연결된 마감일은 유지되고 원본 자료 연결만 해제됩니다. 파일 자료의 수정·업로드·추출은 아직 지원하지 않습니다.

자료 상세의 **원문 추출** 후 Google Gemini로 추출 원문을 전송하는 데 동의하면 **AI 분석 시작**을 사용할 수 있습니다. 추출과 AI 상태를 분리하고 2초 간격의 자동 조회를 최대 90초까지 제공합니다. 분석 결과에서 원문·근거·주의사항을 비교하고 후보를 수정·제외한 뒤 저장·승인하거나 전체 거부합니다. 승인 후에만 실제 마감일이 등록됩니다. [AI 검토 연결 문서](docs/ai-review-flow.md)에 계약·제한·검증 절차를 정리했습니다.

마감일 상세의 **작업 등록**으로 해당 마감일을 미리 선택한 작업을 만들 수 있습니다. 작업의 예상 소요시간, 1~5 우선순위 값, 고정/유동 유형과 선택 가능한 시작·완료 일시를 저장합니다. 시작과 완료 일시를 모두 입력하면 시작이 더 빨라야 합니다. 날짜를 바꾸지 않고 다른 필드만 수정할 때는 서버의 초·밀리초를 보존합니다. 목록과 상세에서 완료/미완료를 전환할 수 있으며 완료 일시는 서버 값으로 표시합니다. 상세 계약과 남은 기능은 [작업 관리 문서](docs/task-management.md)에 정리했습니다.

## 구조

```text
app/                 경로, 레이아웃, 전역 스타일
components/          공통 피드백, 제목, 페이지 이동
features/auth/       인증 API, 사용자 상태, 로그인·회원가입 폼
features/sources/    원본 자료 API와 화면
features/analyses/   AI API, 동의·기록, 후보 검토·승인·거부
features/deadlines/  마감일 API와 화면
features/tasks/      작업 API, 폼, 목록·상세, 마감일별 작업 목록
lib/api/             HTTP·오류 처리, 데이터 조회 훅
lib/auth/            세션 토큰 저장
lib/date/            한국 시간 변환
types/               백엔드 요청·응답 타입
tests/               테스트 전용 API 응답과 브라우저 시나리오
live-tests/          명시적으로 실행하는 실제 서버 검증
docs/                백엔드 연동 및 PR 인계 자료
```

Task CRUD와 AI 검토는 저장소의 현재 API 계약으로 연결했습니다. 일정 배치와 Calendar 연동은 API가 준비되면 `features/schedules`, `features/calendar`에 추가합니다. 현재 미완성 기능의 실행 버튼이나 가짜 분석 결과는 제공하지 않습니다. 운영 코드에는 mock이 없고, 테스트 응답만 `tests/`에 분리되어 있습니다.

## 검증

```sh
npm run lint
npm run typecheck
npm run build
npm test
```

브라우저 테스트는 설치된 Google Chrome을 사용하며 테스트용 환경변수로 빌드한 후 3100 포트에 서버를 자동 실행합니다. 테스트 후 실제 서버를 대상으로 `npm start`를 실행하려면 실제 환경변수로 `npm run build`를 다시 실행해야 합니다. 테스트의 API 응답은 브라우저 요청을 가로채서 제공하므로 실제 계정 생성이나 서버 데이터 변경을 하지 않습니다. 일반 개발 서버에는 적용되지 않습니다. 테스트는 PC/모바일 화면에서 인증·자료 관리·마감 CRUD·작업 CRUD 및 완료 처리·필터/페이지 이동·한국 시간 변환·오류/재시도·401 만료 처리를 확인합니다. PC 테스트의 브라우저 시간대는 `America/Los_Angeles`로 지정하여 한국 시간 변환이 PC 설정에 영향받지 않는지도 검사합니다.

별도 실제 서버 검증은 `PLANCATCH_LIVE_API_URL`에 공개 API 기본 주소를 설정한 뒤 `npm run test:live`로 실행합니다. 기본 `npm test`와 분리되어 있으며 실제 전용 계정을 생성하고 AI 서비스를 호출합니다. 런타임에 임의 비밀번호를 생성하고 비밀정보를 출력하지 않습니다. 새로 만든 `[테스트] Codex AI` 자료·마감일만 정리합니다. 계정 삭제 API가 없어 테스트 계정은 남습니다. 자세한 범위와 주의사항은 [AI 검토 연결 문서](docs/ai-review-flow.md)를 참고하세요.
