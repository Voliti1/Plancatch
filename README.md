# PlanCatch

공개 공고와 캡처에서 마감일을 찾아 검토·등록하고, 할 일과 캘린더에서 관리하는 서비스입니다.

## 구현 범위

| 기능 | 현재 지원 |
|---|---|
| 계정 | 회원가입·로그인·본인 비밀번호 변경, 다크/라이트 모드 |
| URL | 공개 HTML 직접 분석, 동일 공고의 접수기간·기업명·마감일 후보 검토 |
| 이미지·텍스트 | 저장 후 Google Gemini 전송 동의, 추출 후보 수정·선택·승인 |
| 일정 등록 | 선택한 일정 제목을 후보에 전달, 수동 마감일 또는 시작/종료가 있는 할 일 등록 |
| 문장으로 등록 | 내일·요일·다음 주와 시각/소요시간 해석 → 수정 가능한 미리보기 → 확인 후 등록 |
| 목록 | 제목 실시간 검색·일치 부분 강조·선택 삭제·연결 자료 보호 |
| 마감일 | 공식 마감일·사용자 여유시간 기반 안전 마감일·연결 작업 |
| 자체 캘린더 | 월/주 보기, 마감일·고정 일정·수동 배치, 색상 바와 흰색 제목 |
| Google Calendar | 사용자 계정 연결·선택형 조회·명시적 전송·수정·삭제·중복 전송 방지 |

URL은 AI나 이미지 OCR로 자동 보정하지 않습니다. 날짜만 있으면 한국 시간23:59를 제안하고 사용자가 검토합니다.
원문에 명확한 시간이 있으면18:00·18시·오후6시 등의 표기를 보존합니다. 이미 승인한 일정은 재분석으로 자동 변경하지 않습니다.
사이트 구조가 바뀌거나 HTML과 공고 이미지가 다를 수 있으므로 등록 전에 실제 마감일을 확인해야 합니다.

PDF, HEIC/SVG, 여러 페이지·움직이는 이미지, AI 역산 계획·위험도·자동 배치,
Google 전송·수정·삭제는 미리보기와 사용자 확인을 거칩니다. 로컬 변경을 자동 동기화하지 않습니다. [수정·삭제 범위와 복구](backend/docs/google-calendar-changes.md)를 참고하세요.

[문장으로 등록](backend/docs/natural-schedule.md)은 지원하는 한국어 표현을 외부 AI 없이 해석하는 첫 버전입니다.
종료가 없는 할 일은1시간, 시간이 없는 마감일은23:59를 제안합니다. 반복·복잡한 문장은 직접 확인이 필요합니다.

## 개발 시작

- 백엔드: Python3.12·FastAPI·SQLAlchemy·Alembic·PostgreSQL. [설치/실행](backend/README.md)
- 프론트엔드: Next.js App Router·React·TypeScript. [설치/실행](frontend/README.md)
- 로컬 기본 주소: 백엔드 http://127.0.0.1:8000, 프론트엔드 http://localhost:3000.
- 코드의 DB 구조 기준은20261102_0009입니다. 개발 DB를 먼저 설정한 뒤 Alembic으로 적용합니다. 실제 운영 적용 여부는 배포 기록으로 확인합니다.
- `.env.example`은 설정 항목 안내입니다. `.env`, 키 파일, 업로드 이미지, DB 데이터, 설치 환경과 빌드는 Git에 넣지 않습니다.

## 검증

백엔드 폴더에서 `python -m pytest -q`, `python -m ruff check app tests`를 실행합니다.
프론트엔드 폴더에서 `npm ci`, `npm run lint`, `npm run typecheck`, `npm run build`, `npm test`를 실행합니다.
일반 검사는 합성 자료와 외부 서비스 대체 응답을 사용합니다. 실제 개인 캘린더 쓰기나 Gemini 전송 검사는 별도입니다.
